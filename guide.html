빠른 메시지 편집 가이드

그라데이션 색상이 들어간 문구를 만들어 빠른 메시지로 저장하는 방법이에요.

1채팅창에서 ‘빠른 메시지’ 열기

채팅창 오른쪽 아래의 ＋(더보기) 버튼(①)을 누르고 ‘빠른 메시지’를 선택하면 저장된 빠른 메시지 목록이 나와요.

2연필 버튼으로 편집 화면 열기

빠른 메시지 창 위쪽, 제목 옆의 연필 버튼(②)을 눌러요. 화면 오른쪽에 ‘빠른 메시지’ 편집 목록이 열려요.

3수정할 메시지의 연필 버튼 누르기

오른쪽 목록에서 고치고 싶은 메시지 옆의 연필 버튼(③)을 눌러요. 새 메시지를 추가하려면 아래 ＋문자를 누르면 돼요.

목록에서 F는 삭제, Space는 정렬이에요.

4색상 코드 문구 만들기

아래 페이지에서 문구를 만들어요.

  1. 텍스트를 입력해요.
  2. 그라데이션 색상을 고르거나 프리셋을 눌러요.
  3. 뒤에 붙일 이모지를 눌러 태그를 추가해요.
  4. 미리보기를 확인한 뒤 복사하기를 눌러요.
그라데이션 생성기 열기

5붙여넣고 저장하기

게임으로 돌아와 ‘퀵 메시지 수정’ 입력칸의 기존 문구를 지우고, 복사한 문구를 붙여넣기(Ctrl+V) 해요. 입력 가능한 글자 수는 300자까지예요.

내용을 확인했으면 Space(확인)를 눌러 저장해요. 이제 빠른 메시지 목록에서 색이 입혀진 문구를 바로 보낼 수 있어요.

색이 이상하면 문구 앞뒤에 공백이나 글자가 잘못 들어가지 않았는지 확인하고, 생성기에서 다시 복사해서 붙여넣어 보세요.
